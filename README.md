# Sales Dashboard Project

## Overview

The Sales Dashboard project aims to provide insights and visual representations of sales data using data cleansing techniques, along with various Excel functionalities such as pivot tables, pivot charts, slicers, timelines, KPI displays, and various visualization formats. This dashboard can help sales teams and management monitor performance and make data-driven decisions.

## Features

- **Data Cleansing**: 
  - Import and clean sales data from various sources to ensure accuracy and consistency.
  
- **Pivot Tables**:
  - Create dynamic pivot tables to summarize sales data by categories such as product, region, and time period.

- **Pivot Charts**:
  - Visual representation of pivot table data using pivot charts to intuitively display trends and comparisons.

- **Slicers**:
  - Interactive slicers to filter data in pivot tables and charts for enhanced analysis.

- **Timelines**:
  - Utilize timelines to analyze data over different time frames easily.

- **Locked Slicers**:
  - Lock slicers within the dashboard to maintain specific filter values while allowing interactivity elsewhere.

- **Key Performance Indicators (KPIs)**:
  - Display critical metrics such as total sales, average sale value, and sales targets visually through KPI indicators.

- **Dynamic Charts**:
  - Column charts for comparative analysis and line charts for trend analysis over time.

## Technologies Used

- Microsoft Excel (for data analysis and visualization)
- VBA (optional; for advanced interactivity and features)
